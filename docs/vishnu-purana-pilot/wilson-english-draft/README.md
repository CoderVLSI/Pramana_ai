# Wilson's English Vishnu Purana (1840), Book 1 — draft, NOT FOR PUBLICATION

Source: H. H. Wilson, *The Vishńu Puráńa*, John Murray 1840 (public domain; Wilson d. 1860). archive.org item `in.ernet.dli.2015.283854`, Book 1 = image indexes n96–n256 (printed page = index − 95).
Method: main-translation lines selected by type size from archive.org's machine reading of the same scan (`build_draft.py`, `build_book2.py`), ~630 short corrections from three AI proofreaders applied by script (`apply_corr.py`), footnote leaks dropped by rule. **Not yet human-checked.**
Known gaps: the footnote/main-text split failed on some pages, so chapters 1, 2, 3, 7, 10 and 21 are thin (text lost, not just reduced); about 44 leaked footnote entries were dropped by rule, a few may have taken real text with them; 7 corrections remain unapplied; the 22 chapter headings are not all intact. Treat as a draft for a second pass; do not publish to Supabase as complete (it would have to be `completeness: selected`).
`book1-draft.json`: entries {kind, book, chapter, verse (paragraph no.), page_index, text}.
