## What this means
The ancient verses are old, but every digital copy found so far carries terms from whoever typed it. The cleanest routes are: written permission from the typists/hosts (Sanskrit Documents volunteers, GRETIL, BORI), or a source with a clearly open licence (for example CC BY, CC0) that a reviewer confirms. Until then, do not publish any of these files to the Supabase library.
