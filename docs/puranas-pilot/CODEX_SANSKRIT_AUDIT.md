# Codex job: leaf inventory and chapter map for the Sanskrit editions of the other Mahapuranas (no scripture text is copied)

Goal: turn the research in `docs/puranas-pilot/source-candidates.md` into a precise, checked MAP of each Purana's best old Sanskrit scan, so that transcription can start without guessing page numbers. This is an audit job. Copy no scripture text.

Scope: the 17 Mahapuranas other than the Vishnu Purana (work ids in `packages/corpus-schema/register.ts`, MAHAPURANA_TARGETS) plus Vayu (supplementary). Start with those the research rated "Sanskrit possible" with the clearest scans — Brahma, Padma, Linga, Varaha, Kurma, Vayu, Brahmanda, Narada, Vamana, Skanda (Sahyadri-khanda only) — then Markandeya (Jivananda 1879), Agni (Calcutta 1890), Garuda (Jivananda 1890), Matsya (Jivananda 1876), Bhagavata and the rest where a candidate scan exists. Shiva and Bhavishya: only record what blocks them.

For each Purana, using the scan chosen in the research file (re-check it; if another archive.org copy of the same edition has clearer images, say so):
1. **Chapter map**: for every adhyaya, the archive.org image index (n) where it begins, found from the machine-read text (`_djvu.xml`) headings AND confirmed by looking at the page image. Where the machine reading garbles a heading, interpolate from the sequence but mark that row `unconfirmed`. Output a table `adhyaya, start_image, end_image, verse_count_if_printed, status`. Expected chapter count per the printed contents; flag mismatches.
2. **Leaf inventory**: every image index in the main-text range classified (root text, commentary-only, blank, title/wrapper, index, damaged/missing). List missing or illegible leaves explicitly. Do not claim completeness you did not check.
3. **Type quality**: sample at least 5 pages spread through the book (include first, middle, last) and grade each A (large, clear), B (readable with care), C (small/blurred; unreliable). Say whether root text and commentary are separable by size/position, and whether verse numbers are printed.
4. **Layout notes** a transcriber needs: columns or single column, how verses end, how chapter colophons are printed, prose passages, line-break hyphenation, anything unusual.
5. **Second witness**: is there a second independent pre-1931 Devanagari edition scan (different press/editor)? Give its item id and the same quick grade, or say none found.
6. **Pilot recommendation**: the single easiest adhyaya to start with and its image range.

Rules: do not copy, quote or commit scripture text (titles, headings, adhyaya numbers, image indexes and short bibliographic quotes are fine). Do not use GRETIL, Sanskrit Documents, Wikisource, Gita Press or any modern edition as a text source or as the chapter list (leads for finding scans only; chapter counts must come from the printed contents of the scan itself). Do not change apps/, packages/, services/, workflows or secrets. Do not publish anything. If a download or image cannot be viewed, say so and mark the rows unconfirmed; never fill them in from memory.
Write one file per Purana `docs/puranas-pilot/sanskrit-maps/<work-id>.md` plus a summary table in `docs/puranas-pilot/sanskrit-maps/SUMMARY.md` (columns: work, scan item, chapters mapped / expected, leaves classified, quality grade, second witness, pilot adhyaya, blockers). Commit and push to the working branch after each Purana. Stop and report if you hit a usage limit. Report short counts only.
