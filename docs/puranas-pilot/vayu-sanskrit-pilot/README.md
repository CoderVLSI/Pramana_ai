Source: *Vāyupurāṇam*, ed. Only one edition is available, so the check is two blind readers of the same scan plus an arbiter who looks at the page image for every difference; this catches careless reading errors but cannot catch damage in the print itself.
`vayu_ch1_A.json` (189 entries: 50 high / 109 medium / 30 low) and `vayu_ch1_B.json` (188 entries: 17 high / 140 medium / 31 low), both with verses 1–185 and no number missing. Both readers note that the font prints क्ष and श like other letters and that ८/९ look alike; closing numbers were taken from the sequence in places. Arbiter pass in progress.
