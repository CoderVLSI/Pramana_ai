# Upanishad drafts from the 1925 Nirnaya Sagar "108 Upanishads" — NOT FOR PUBLICATION

AI first-pass readings of page images (archive.org item `in.ernet.dli.2015.427659`, printed page = image index − 16). **Unreviewed and not publishable.** Readers reported blurry scans and, in places, guessed or "usual" readings (R3 admits reconstruction from memory; R9 Garuda serpent mantras rebuilt from a printed formula; R7 Annapurna/Adhyatma/Kundika typed from partial views; R6 page_index only approximate). Most entries are `medium`/`low` confidence.

Files: R1 (Amritabindu–Maitrayaniya), R2 (Nrisimha–Vajrasuchi), R3 (Tejobindu–Atmabodha), R4 (Naradaparivrajaka), R5 (Mahanarayana–Shandilya), R6 (Paingala–Paramahamsaparivrajaka), R7 (Akshamalika–Avadhuta), R8 (Tripuratapini–Darshana), R9 (Tarasara–Sarasvatirahasya). Not yet read: Rudrakshajabala (R8 skipped it). Kaushitaki, Brihajjabala: see the main transcription file (pending re-read).

A second reading of Garuda from the Adyar 1923 volume (`V2_garuda.json`, scan only ~515×808 px) matched the first reading exactly for 1 of 26 verses and to ≥95% for 12, so a second-printing check does not make these publishable. Publish only after a clearer scan or human review. The Gita and the 11 principal Upanishads (1906 edition) are the only texts live.
